# Hướng dẫn cài đặt - Install Instruction


Các yêu cầu - requirements:

- node v25+
- npm 11+

## Hướng dẫn cơ bản
**Bước 1 (Step 1)**: Clone repo
```bash
git clone https://github.com/chpvchp/edu-sw.git
```

**Bước 2 (Step 2)**: Cài đặt gói phụ thuộc - Install dependency package
```bash
npm install
```

**Bước 3 (Step 3)**: Dev in http://localhost:5173
```bash
npm run dev
```
